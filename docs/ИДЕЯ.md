# Идея — Content Factory

**Дата:** 2026-07-05 · **Обновлено:** 2026-07-09
**Статус:** Фаза 1 + промпт-слой + Magnific-бэкенд (картинки) + видео-паспорта + видео-бэкенд Dreamina (Seedance) — реализованы; концепция стабильна.

## В одном предложении

**Content Factory** — генеративный слой для агента **Hermes**: отдельный MCP-сервер `generation-factory`, который даёт Hermes простые инструменты, чтобы вести визуальный препрод по проекту (черновики → финалы → сборка кадров), храня всё внутри одной папки проекта.

## Зачем

У пользователя есть студийный конвейер (подряды Lion Films + собственная AI-студия). Раньше им управлял тяжёлый агент `Q:\Lion Films. AI studio` — зрелый lifecycle-фреймворк (~20 Python-модулей, 9 агентов, реестры-гейты `00_brief..05_review`). Но **реальная ценность там — только генерация**; вся машинерия (scaffold/lint, `reference_register`/`shot_registry`, QA-promotion, iteration-gating) избыточна и противоречит принципу простоты.

**Content Factory забирает из старого агента только генеративное ядро** и переупаковывает его в чистый MCP-сервер, которым оркестрирует сам Hermes — без постоянной агентуры и реестров.

## Ключевой принцип

> **Одна папка = один проект. Всё касающееся проекта — внутри неё. Чем проще, тем лучше.**

Никаких внешних областей `WORK`/`projects_live`, никаких накопительных реестров-гейтов. Continuity (сквозные персонажи/локации) достигается **переиспользованием кирпичей-building-blocks**, а не авто-реестром: «тот же персонаж в новой локации» = то же лицо из `characters/<name>/` + другая готовая `locations/<name>/`.

## Как это работает (поток)

1. Пришёл агентский бриф → Hermes раскладывает материалы: лицо → `references/characters/`, локация-референс → `references/locations/`, стиль → `references/look-and-feel/`, раскадровка → `storyboards/`.
2. «Создай кухню» → **дешёвые черновики** (ComfyUI, локально на RTX 4070) → выбор → сохранение в кирпич `locations/kitchen/`.
3. «Собери кадр 1» → **финал** (сборка лицо+локация с multi-референсами) → `generated/<дата>/shot-01/` + промпт в `prompts/`.
4. Работа по кадрам по очереди; память процесса — чтение прошлых удачных промптов.
5. «Контакт-лист за сегодня» → сборка по запросу (не авто).

## Роли бэкендов

- **ComfyUI** (локально) — массовые дешёвые черновики; кандидат на роль основного генератора стиллов.
- **Nano Banana** (внешний Express/Gemini-сервер) — задумывался как основной финал с multi-референсами. **Заблокирован** (нет доступа к модели `gemini-3-pro-image-preview`) → роль финала перенимает Magnific.
- **Magnific API** — **реализовано (2026-07-09, коммит 99d7849):** **третий бэкенд завода** для генерации картинок. Завод сам ходит к `api.magnific.com` по REST (модель + промпт + референсы base64 + скачивание CDN-URL), с единым бюджет-гейтом, провенансом и хранилищем — вместо того чтобы Hermes звал Magnific-MCP напрямую. Главный кандидат на финалы «лицо+локация» — Seedream 4.5 Edit (замена заблокированному Nano). Live-смоук mystic пройден. Спека: `superpowers/specs/2026-07-06-magnific-backend-design.md`.
- **Видео (Veo / Seedance / Wan / Runway / Kling)** — генерации видео завод пока **не исполняет**, но промпт-слой учится **писать промпты** под них (паспорта, явный режим `gf_write_prompt`). Seedance имеет известный путь исполнения — **Dreamina CLI (JiMeng / 即梦)**, отработанный в старом заводе. Генерация видео заводом — будущая фаза (оркестрация Dreamina CLI по образцу `videogen/backends/dreamina.py`).

## Промпт-слой (промпт-райтер)

Hermes (deepseek) пишет слабые промпты — не знает синтаксис конкретной модели, теряет контекст брифа. Поэтому написание промпта вынесено в отдельный слой: один вызов Claude API по markdown-«паспорту» модели (`gf/promptdocs/<platform>/<model>.md`) превращает сырую задачу в грамотный промпт. Работает автоматически внутри `gf_generate_*` и явно через `gf_write_prompt` (в т.ч. для площадок/моделей, которые завод не исполняет — Hermes получает промпт и зовёт их сам). Спека: `superpowers/specs/2026-07-06-prompt-layer-design.md`.

## Не-цели

- Не переносим старую структуру `00_brief..05_review`, `.lf_project`, scaffold/lint.
- Не тащим реестры-гейты и QA-promotion.
- Не держим постоянную агентуру — оркестрирует Hermes.
- Не делаем авто-сборку контакт-листов (только по запросу).
- Пока не **исполняем** видео-генерацию заводом (только пишем промпты под видео-модели); реальная видео-генерация — отдельная будущая фаза.

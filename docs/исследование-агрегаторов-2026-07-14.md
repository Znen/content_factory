# Исследование: через какой агрегатор выгоднее подключить бэкенды контент-завода

> **Дата:** 2026-07-14
> **Метод:** deep-research (6 углов → 24 источника → 106 утверждений → 25 проверено адверсариально 3 голосами → 20 подтверждено, 5 опровергнуто).
> **Актуальность цен:** 1-я половина 2026. Nano Banana Pro запущен ~ноя 2025, Seedance 2.0 API открыт апр 2026. Цены на генеративные модели меняются очень быстро — **перепроверить перед интеграцией.**

## Задача

Выяснить, через какой API-агрегатор выгоднее всего подключить:
- **(a)** генерацию изображений на Google **Nano Banana Pro** (Gemini 3 Pro Image);
- **(b)** генерацию видео на ByteDance **Seedance 2.0**.

Допустимо использовать **разные** агрегаторы для картинок и видео. Критерий «выгодности» — **совокупный**: цена за единицу ВМЕСТЕ с надёжностью, скоростью, наличием async-REST и отсутствием обязательной подписки. Профиль: средний объём (сотни генераций/мес), pay-as-you-go предпочтительнее подписки. Оплата из РФ не является ограничением.

### Рекомендация по картинкам

- **Максимальная экономия:** **Kie.ai** — $0.09/$0.12, на ~33% ниже Google (1K/2K) и ровно −50% (4K), PAYG без подписки, порог входа $5. ⚠️ Но async-REST с polling для Nano Banana Pro на Kie.ai источниками не подтверждён — критично для бэкенда, надо проверить самим.
- **Надёжность + удобство:** **fal.ai** — дороже ($0.15/$0.30), но единственный с подтверждённым зрелым async-REST и SLA 99.99%. При «совокупном» критерии — сильный кандидат.
- Разница в деньгах на объёме (сотни/мес) невелика: 500 картинок 1K/2K = $45 (Kie) против $75 (fal) → **$30/мес**. За надёжность бэкенда это немного.

### Рекомендация по видео

- **Лучший по совокупности:** **EvoLink** — единственный с **документированным** async-REST (`POST /v1/videos/generations` + polling по task_id, Bearer-auth), без watermark, коммерческое использование, биллинг «платишь только за успешные задачи» (HTTP 4xx не тарифицируются). Для бэкенда контент-завода ложится идеально — по сути замена CLI-обёртки Dreamina на чистый REST.
- **Самый дешёвый за секунду:** **OpenRouter** — пол $0.067/с, но токенная формула зависит от разрешения/длительности; точную цену на 720p/1080p×5-10с нужно пересчитать (см. открытые вопросы).
- **PiAPI** — почти как EvoLink по цене, чуть дороже на 720p/1080p, с более дешёвыми mini/fast-вариантами, если качество допускает.

## Как это ложится на контент-завод

Текущее состояние (из карты проекта): **Magnific** для картинок nano-banana-pro и **Dreamina CLI** для Seedance.

| Что | Сейчас | Что даёт исследование |
|---|---|---|
| Картинки Nano Banana Pro | Magnific REST | Kie.ai дешевле, fal.ai надёжнее + чистый REST. Цена Magnific в отчёте не всплыла — сравнить с фактическим тарифом Magnific |
| Видео Seedance | `dreamina.exe` (subprocess, `_parse_result` спекулятивный, не верифицирован live) | **EvoLink REST** снимает главный риск фазы VG — уходит хрупкий CLI-парсинг, приходит документированный async-API. Сильный аргумент к миграции видео-бэкенда |

**Ключевой вывод:** переход видео с Dreamina-CLI на **EvoLink REST** закрывает сразу два открытых риска проекта — спекулятивный `_parse_result` и отсутствие атомарности в `video_jobs` (REST + polling надёжнее subprocess).

## ⚠️ Оговорки

1. **Метрик надёжности (аптайм/латентность/rate limits) в подтверждённых источниках почти нет** — «надёжность» fal.ai/OpenRouter оценена по репутации, а не по замерам.
2. Vendor-страницы **Kie.ai отдавали HTTP 403** при прямом fetch → подтверждение по 3 сторонним обзорам (сила ниже, чем у Google/fal.ai/OpenRouter/EvoLink с прямыми первичными источниками).
3. Многие агрегаторы (OpenRouter, Google) тарифицируют **по токенам**, а не «за изображение/за клип» — прямое сравнение требует пересчёта под разрешение и длительность.
4. Reseller-цены (EvoLink, Kie.ai, PiAPI) могут содержать скрытые надбавки за режим/референсы/аддоны/grounding.
5. Доступность Seedance 2.0 на fal.ai/Replicate/Runware/WaveSpeed **не подтверждена** первичными ценами.

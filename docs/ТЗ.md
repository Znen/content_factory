# Техническое задание — Content Factory (`generation-factory`)

**Дата:** 2026-07-05
**Статус:** Фаза 1 — выполнена; Фазы 2–4 — планируются.

## 1. Назначение

Отдельный MCP-сервер, дающий агенту Hermes генеративные инструменты для визуального препрода. Ставится рядом с уже подключёнными к Hermes `knowledge-factory` и `magnific`.

## 2. Функциональные требования

### 2.1. MCP-инструменты

| Инструмент | Фаза | Что делает |
|---|---|---|
| `gf_generate_draft(project, prompt, n, negative, seed)` | ✅ 1 | N дешёвых черновиков через ComfyUI → `media/generated/<дата>/_drafts/draft-NN.png` |
| `gf_generate_final(project, prompt, refs[], aspect)` | ✅ 1 | Финал через Nano Banana (≤4 multi-референса) → `media/generated/<дата>/` |
| `gf_save_asset(project, image, kind, name)` | ⬜ 2 | Сохранить выбранное в кирпич `locations/<name>/` или `characters/<name>/` |
| `gf_assemble_shot(project, shot, character, location, prompt, date)` | ⬜ 2 | Сборка кадра (лицо+локация multi-ref) → `generated/<дата>/shot-XX/` + промпт в `prompts/` |
| `gf_contact_sheet(project, selection)` | ⬜ 3 | Контакт-лист ПО ЗАПРОСУ (за дату / последние N / список) |

`project` — абсолютный путь к папке проекта; Hermes передаёт его явно.

### 2.2. Раскладка медиа проекта (storage-спека)

```
<project>/media/
├── references/{characters,locations,look-and-feel}/   ← входящее из брифа
├── locations/<name>/                                  ← созданные кирпичи-локации
├── characters/<name>/                                 ← утверждённые персонажи
├── generated/<YYYY-MM-DD>/
│   ├── _drafts/draft-NN.png
│   └── shot-XX/{iter-*.png, prompts/iter-*.json}
└── storyboards/
```

### 2.3. Промпты / память процесса

- Промпты сохраняются рядом с картинками: `generated/<дата>/shot-XX/prompts/iter-*.json` (промпт + backend + референсы + seed + дата), связь по имени.
- Назначение: (а) отдать клиенту; (б) воспроизвести удачное / избежать неудачного. Hermes перед новым кадром читает прошлые удачные промпты.

### 2.4. Cost-gating

- Каждая генерация логируется в `<project>/media/.gf_cost_log.jsonl` (оценка стоимости).
- Опциональный мягкий кап `GF_IMAGE_CAP_USD`: генерация, превышающая накопленный лимит проекта, **отклоняется** (возврат `{"error": ...}`, ничего не генерируется).
- Нулевая стоимость (локальный ComfyUI) **не блокируется** капом никогда.

## 3. Нефункциональные требования

- **Портируемость / local-first:** без внешних облачных зависимостей в ядре; всё локально (ComfyUI на RTX 4070, Nano-сервер на localhost). Секреты — вне репозитория.
- **Платформа:** Windows 11, Python ≥ 3.10 (проверено на 3.10.11).
- **Пакет:** `gf`; CLI `gf`; env-префикс `GF_`; MCP-имя `generation-factory`; порт по умолчанию **8766** (чтобы не биться с kf `:8765`).
- **Транспорты MCP:** stdio (по умолчанию, для локального Hermes-subprocess); HTTP+bearer (`hmac.compare_digest`) когда задан `GF_MCP_TOKEN`; plain streamable-HTTP иначе.
- **Тесты:** каждый модуль покрыт; HTTP-бэкенды тестируются с инъекцией фейковой сессии (без сети). Реальные внешние вызовы — за маркером `live` (`GF_RUN_LIVE=1`).
- **Простота:** без pydantic (обычный `@dataclass` config), без БД-стека (в отличие от kf).

## 4. Бэкенды и их текущий статус

| Backend | Роль | Статус |
|---|---|---|
| **ComfyUI** | дешёвые черновики; кандидат в основной генератор стиллов | ✅ **прогнан против живого ComfyUI** (2026-07-05): реальный draft работает end-to-end |
| **Nano Banana** | финал по промпту/референсам | клиент готов и отвязан; **заблокирован**: Gemini 403 — ключ без доступа к `gemini-3-pro-image-preview` |
| **Magnific** | видео + TTS (ElevenLabs); возможно апскейл | у Hermes отдельным MCP; **не** генерит статичные картинки; gf его не оборачивает |
